# 🛡️ TrustSecAI 2027

### 1st International Workshop on AI Security & Trustworthy Autonomous Cybersecurity

**Beyond Detection. Toward Autonomous Defense.**

📍 **Delft, Netherlands** | 📅 **13–15 April 2027**

In conjunction with the [18th International Conference on Ambient Systems, Networks and Technologies (ANT 2027)](https://cs-conferences.acadiau.ca/ant-27/).

[🌐 Official Website](https://rayentech.github.io/TrustSecAI2027/) | [📝 Paper Submission](https://easychair.org/conferences/?conf=trustsecai2027)

## 🔵 About the Workshop

**TrustSecAI 2027** brings together researchers, academics, and industry professionals to explore the security, reliability, and trustworthiness of AI systems and autonomous cybersecurity technologies.

## 🟣 Topics of Interest

- AI Security and Adversarial Machine Learning
- Security of LLMs and Generative AI
- Autonomous Cyber Defense and Agentic Security
- AI-Driven Threat Detection and Incident Response
- Explainable, Privacy-Preserving, and Trustworthy AI
- Security Evaluation, Benchmarks, and Applications

## 🟢 Call for Papers
